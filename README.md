"Cari Bedanya — Taman, Pantai & Kamar Mochi": a spot-the-difference game with three hand-drawn scenes. Find 7 differences per level before the 2:30 timer runs out — wrong clicks cost 5 seconds. Play it with mouse and keyboard (H hint, P pause, M sound, R retry level).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
